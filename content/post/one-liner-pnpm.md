## One-Liner series: pnpm

[source: pnpm docs](https://pnpm.io/installation)

### Install on Linux

```bash
curl -fsSL https://get.pnpm.io | sh -
```

### Install on Windows (PowerShell)

```powershell
irm https://get.pnpm.io/ps1 | iex
```

### Update

```bash
pnpm self-update
```
